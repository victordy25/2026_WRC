1. 엑스포 개요 & 테마 데이

올해 처음으로 일자별 테마 데이가 도입되어, 방문 목적에 따라 날짜 선택이 중요해졌습니다.

8/19 (수) · 발표의 날 (Release Day) — 주요 성과·신제품 최초 공개·협력 발표가 집중. 신제품 위주라면 이날 오전 C관
8/20 (목) · 구매상담의 날 (Procurement Day) — 구매 상담회·공급망 매칭 세션 운영. 소싱 목적이면 이날 B·A관
8/21 (금) · 개발자의 날 (Developer Day) — 전 세계 개발자 기술 교류. SDK·플랫폼 논의에 최적
8/22~23 (토·일) · 일반 공개일 (Public Open Days) — 최대 혼잡. 가족 단위는 D관 퍼포먼스 중심 권장
티켓: 대회와 로봇대회(World Robot Contest) 티켓 상호 할인 적용. 기업·대학·연구기관 전문 관람객은 전 기간 통합 이용 가능한 All-Access Pass 구매 가능.

2. 전시관 배치 개념도

주최 측이 공개한 관 순서(북→남)와 관별 전시 구성을 존(zone) 단위로 재구성했습니다. 아래 버튼으로 동선을 배치도 위에 겹쳐 볼 수 있습니다.

공식 배치도(展位图)를 그대로 옮긴 것이 아니라 관 순서·구성 정보로 재구성한 개념도입니다. 존 코드(C1~C6, B1~B6, A1~A6, D1·D2)는 동선에서 그대로 사용합니다. 개별 부스 번호와 통로는 현장 배치도를 확인하세요.

3. 배치도 기반 추천 동선

4개 관이 북→남 일렬 배치라는 점을 활용해, 되돌아오는 구간을 최소화한 4가지 동선입니다.

1반나절 · 휴머노이드 집중
동선: C관 단일 집중 (약 3~4시간)
  1. 북측 입구 → C관 진입 (신축관, 동선이 넓어 체류 시간 대비 효율 높음)
  2. ① 혁신센터 축: 국가-지방 공동 → 베이징 → 상하이/저장/후베이/광둥/쓰촨/지린 순서로 일렬 관람
  3. ② 브랜드 축: Unitree → UBTECH → Galbot → Fourier → LimX Dynamics(Luna 군집 시연) → Magiclab
  4. ③ 특설 구역: JD 슈퍼 전시구역 → 중앙기업관
  5. 시간이 남으면 C관 남단에서 B관으로 바로 연결
혼잡 회피: 시연 로봇은 오전 첫 회차가 가장 안정적. Luna 군집 공연·Tiangong Omni는 회차 시간 사전 확인
2하루 · 공급망 & 부품 소싱
동선: B관 → A관 (남향 연속 이동)
  1. B관 글로벌 축부터: AMD → Infineon → Realtek/RealSense → maxon → FAULHABER → Harmonic Drive → Schaeffler → NSK → igus → MISUMI → Henkel/3M
  2. 이어서 한국관: 로보티즈(AI Sapiens) → 뉴로메카 → 뉴빌리티 → 솔리드뷰 → SENES → AidALL → Dynamic Solution
  3. B관 센서 축: Hesai → Orbbec → ZVISION → Slamtec → 柯力/鑫精诚/他山
  4. B관 손·관절 축: 灵心巧手 → 因时 → 兆威 → 强脑 → 大寰 → 帕西尼
  5. 남쪽 A관으로 이동해 국산 감속기·모터 축: 绿的谐波 → 来福 → 科峰 → 鸣志 → 雷赛 → 新剑 → 清能德创 → 本末动力
  6. A관 센서 보완: Livox(A관 배치)
B관(글로벌)→A관(국산) 순서로 보면 같은 부품군의 가격·성능 대체안을 바로 교차 검증할 수 있음. 8/20 구매상담의 날과 겹치면 매칭 세션 병행
3하루 · 응용 도입 검토 (도입 담당자)
동선: A관 → C관 (역방향 북상)
  1. A관 서비스 축: KEENON → PUDU → 云迹 → Ecovacs → Haier → 美丽魔方 (서빙·배달·청소·가정)
  2. A관 산업 축: Flexiv → ROKAE → Fairino → 新时达 → 中信重工 → 国兴智能 → 申昊 (제조·순찰·특수)
  3. A관 의료 축: 长木谷(ROPA6) → 强联智创 → 程天科技 → 中电科机器人
  4. 북상하여 C관 JD 슈퍼 전시구역에서 물류·리테일·산업·가사 통합 시나리오 확인
  5. 마무리로 C관 중앙기업관에서 국유기업 도입 사례 12개 현장 확인
실제 도입 사례 → 완제품 사양 → 통합 운영 순서로 보면 견적 협의에 필요한 정보가 자연스럽게 축적됨
4가족 · 체험 중심
동선: D관 → A관 → C관 (남→북)
  1. 남측 D관(임시관 2동)에서 시작: 加速进化 · 莫刻机器人 · 泓柯智行 로봇 퍼포먼스
  2. 안노(安诺) AI 아이스크림 부스, 陆吾智能 데스크톱 로봇, 心言 가정 동반 로봇 체험
  3. 大象机器人 · 松灵 · 穿山甲 등 교육·이동 로봇 체험
  4. 북상하여 A관 서비스 로봇(서빙·청소) 체험 후 C관 휴머노이드 시연 관람
  5. 로봇 쇼핑 스트리트(로봇 셰프 조리·굿즈)와 BCI 뇌제어 로봇 체험 세션 병행
D관은 임시관이라 옥외 이동 구간이 발생 — 더위·비 대비 필요. 주말(8/22~23)은 혼잡하므로 개장 직후 입장 권장
